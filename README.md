# Payment Verifier — Release Candidate 3.1.2-rc1

This package is the WordPress/WooCommerce release candidate after API,
database, order-transition, and idempotency hardening.

## Scope

- REST API
- authentication/scope controls
- WooCommerce order integration
- payment verification flow
- idempotency and duplicate protection
- order transition guard
- audit/correlation support
- admin diagnostics
- staging runbook

## Important

This is a **release candidate**, not a production certification.

The remaining gates require execution on a real staging WordPress/WooCommerce
installation and, later, an Android build/runtime environment.
